# fritzsch-manuscript
Dynamic Flavor Mixing Through Transition Moments

## abstract
We show that Majorana neutrino flavor mixing can be driven by transition dipole moments in the presence of external electromagnetic fields. We demonstrate the sensitivity of the rotation mixing matrix to strong fields obtaining effective mass eigenstates in the two-flavor model.
